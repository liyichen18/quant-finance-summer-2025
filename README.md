# Quant Finance Summer 2025

This repository contains my work from the Quant Finance Boot Camp (Summer 2025) organized by the Erdös Institute. The program was led by Professor Thomas Polstra and ran from May 8 to August 15, 2025.


# Overview
The Quantitative Finance Boot Camp provided a rigorous introduction to probabilistic methods and Python applications in financial markets. Topics covered included:

Portfolio construction and optimization

Stock return distribution analysis

Options pricing and Greeks under the Black-Scholes model

Delta hedging strategies under stochastic volatility models (Regime Switching, Heston, GARCH)

Market making and risk management strategies


# Repository Structure
Lecture/: Summarized lecture notes from course videos and readings

Quant Finance Mini Projects/: My mini-projects covering portfolio analysis, normality testing, option Greeks visualization, and delta hedging simulations

README.md: Project description and repository guide

# Key Projects
Portfolio Volatility Analysis
Constructed high- and low-volatility portfolios to examine the risk-return tradeoff using real market data.

Return Distribution Normality Testing
Applied statistical tests and visualization to assess normality assumptions in asset returns.

Option Greeks and Sensitivity Analysis
Analyzed Delta, Gamma, Vega, and Theta sensitivities under Black-Scholes assumptions.

Delta Hedging under Stochastic Volatility
Simulated hedging performance under Regime Switching, Heston, and GARCH models, highlighting model risks and tail events.
